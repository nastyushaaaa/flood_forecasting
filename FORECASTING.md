# Модели уровня воды в Хабаровске

## Файлы

- `amur_five_models.xlsx` — пять исходных временных моделей с дополненными показателями.
- `amur_monthly_models.xlsx` — пять отдельных моделей с сезонностью по месяцам.
- `results/metrics_by_lead.csv` — MAE, RMSE, NSE, S/σΔ, P и σΔ для каждой модели и заблаговременности 1–30 суток. `p` хранит долю 0–1, `p_percent` — проценты 0–100.
- `results/rolling_validation.csv` — проверочные прогнозы, фактические и начальные уровни, даты выпуска и окончания обучения, признаки включения в оценку.
- `results/baseline_daily_forecast.csv` и `results/monthly_daily_forecast.csv` — посуточный прогноз на 30 дней, стандартные ошибки и условные 95%-ные границы.
- `results/assessment.json` — коэффициенты полной оценки и промежуточных переоценок, ковариации, исходный фрагмент для проверки, параметры оценки и SHA-256 CSV.
- `data/amur_khabarovsk_clean_2002-2026.csv` — неизменённый исходный файл.

Последняя дата исходного файла — **01.08.2026**. Прогноз начинается **02.08.2026**. В файле нет более поздних наблюдений. Числовая шкала исходного уровня сохранена. Обозначение **см принято по указанию пользователя**; сам CSV не содержит описания единиц и нулевой отметки гидропоста.

## Функции

| Вид | Базовая функция | Сезонная функция |
|---|---|---|
| Полином 2 | H=a0+a1·u+a2·u² | та же функция + cₘ |
| Полином 3 | H=a0+a1·u+a2·u²+a3·u³ | та же функция + cₘ |
| Степенная | H=a·x^b | a·x^b+cₘ |
| Логарифмическая | H=a+b·ln(x) | a+b·ln(x)+cₘ |
| Экспоненциальная | H=a·exp(b·x) | a·exp(b·x)+cₘ |

`t` — календарный номер дня, 01.01.2002 соответствует t=1. `x=t/1000`. `u=2·(t−1)/(T−1)−1`, T — календарная длина соответствующего обучающего периода.

`cₘ` — поправка для месяца прогнозируемой даты. Все 12 поправок оцениваются совместно с трендом по МНК, с ограничением суммы поправок, равной нулю. В расчёте используются 11 независимых месячных контрастов. Внешние погодные факторы и уровни других гидропостов не используются. Начальный уровень из проверочной таблицы нужен только для расчёта σΔ и не входит в прогнозную функцию.

Месячные поправки меняются ступенчато первого числа месяца. Это календарная сезонность, а не физическая модель паводковой волны.

Полиномы и логарифмическая модель оцениваются линейным МНК. Для степенной и экспоненциальной функций используется нелинейный МНК в исходной шкале уровня: профильный поиск по b в [-10,10], а остальные параметры при каждом b находятся линейным МНК. Для сезонных функций месячные эффекты участвуют в том же совместном расчёте. Уровень воды не логарифмируется и не сдвигается, отрицательные значения не удаляются из-за знака.

Основные реализации: `common.py`, `seasonal_models.py`. Отдельные файлы функций: `polynomial2.py`, `polynomial3.py`, `power.py`, `logarithmic.py`, `exponential.py`; сезонные варианты имеют префикс `monthly_`.

## Проверка прогнозов

Проверяются целевые даты **02.08.2025–01.08.2026**, всего 365 календарных дней. Для каждой заблаговременности h=1…30 дата выпуска равна целевой дате минус h суток.

Параметры переоцениваются раз в месяц. Для любого выпуска применяется версия, обученная по последний день предыдущего месяца относительно даты выпуска. Все обучающие даты строго раньше даты выпуска. Например, для выпуска 01.08.2025 применяется обучение до 31.07.2025. Это скользящая ретроспективная проверка с последовательным обновлением моделей, а не один прогноз из единственной точки начала.

В обучении используются только строки с `level_khabarovsk_filled=0`. В оценке принимаются только пары, у которых и целевой, и начальный уровни имеют флаг 0. Базовые и сезонные модели оцениваются на одинаковых парах. При h=1 остаётся 355 проверочных прогнозов.

Это новая схема проверки. Прежний MAE на последних 30 сутках из одной даты начала не сопоставим с новыми значениями без учёта изменения периода и схемы обновления.

## Показатели

Обозначения: eᵢ=Hᵢ−Ĥᵢ, n — число включённых проверочных пар для одного и того же h.

- **MAE=Σ|eᵢ|/n**, см.
- **S (RMSE)=sqrt(Σeᵢ²/n)**, см. Здесь знаменатель n, поскольку оцениваются проверочные прогнозы. Это не стандартная ошибка остатков обучения с делением на n−p.
- **NSE=1−Σeᵢ²/Σ(Hᵢ−mean(H))²**. Среднее берётся по фактическим уровням тех же проверочных пар. При NSE=0 ошибка равна ошибке постоянного среднего, отрицательное значение означает худший результат.
- **Δᵢ(h)=H(дата цели)−H(дата выпуска)**. **σΔ(h)=sqrt(Σ(Δᵢ−mean(Δ))²/(n−1))**, см. В этой работе σΔ оценивается по проверочным изменениям отдельно для каждого h. Это стандартное отклонение изменений уровня, а не стандартное отклонение самих уровней.
- **S/σΔ=RMSE/σΔ**. Ориентиры: ≤0,50 — хорошо, 0,50–0,80 — удовлетворительно, >0,80 — неудовлетворительно.
- **P%=100·count(|eᵢ|≤0,674·σΔ)/n**. В Excel доля хранится числом 0–1 и показывается процентным форматом.
- **R² обучения=1−SSEобуч/SSTобуч** оставлен для связи с прежней книгой. Он рассчитан на обучающей истории и не подменяет проверочный NSE.

NSE сравнивает модель со средним уровнем. Для краткосрочного прогноза этого сравнения недостаточно: отдельно показаны S/σΔ и P, связанные с изменениями относительно начального уровня. Пороги приведены как ориентиры из гидрологической литературы Гидрометцентра. Один год проверки без разделения на половодье, паводки и межень не означает формального допуска методики в оперативную практику.

## Стандартная ошибка посуточного прогноза

Для полного обучения s=sqrt(SSE/(n−p)), Cov(β)≈s²·inverse(JᵀJ). Стандартная ошибка отдельного будущего наблюдения: SEпр=sqrt(s²+gᵀCov(β)g). Стандартная ошибка среднего тренда: SEср=sqrt(gᵀCov(β)g).

Для сезонных моделей ковариация учитывает и базовые коэффициенты, и месячные эффекты, включая их перекрёстную ковариацию. Для нелинейных моделей используется линеаризация. 95%-ные границы равны Ĥ±t·SEпр. Они условны: независимость и постоянство дисперсии ошибок временного ряда здесь не подтверждены. SE не следует подменять проверочным RMSE или считать подтверждённой оценкой вероятности затопления объекта.

## Excel

В каждой книге шесть листов: сводка и пять моделей. Calibri 11, чёрный цвет, без заливок, стандартная сетка, компактные таблицы.

На листе **Сводка**:

- **B3** — число будущих суток в таблице, 1–90, по умолчанию 30.
- **B11** — заблаговременность проверочных прогнозов, 1–30 суток, по умолчанию 1. При изменении этой ячейки пересчитываются проверочные таблицы, σΔ, допустимая ошибка и все проверочные показатели.
- **B12:B13** — ориентиры 0,50 и 0,80 для отношения S/σΔ.
- **B14** — коэффициент допустимой ошибки 0,674.

На модельных листах: коэффициенты слева; месячные эффекты в сезонной книге в D4:E15; показатели в F4:G13; будущий прогноз в A19:H108; проверочные даты и ошибки справа, начиная с J19. Ниже проверочных дат находятся версии коэффициентов по датам обучения. Справа на сводке сохранены фактические уровни и флаги для воспроизводимого расчёта начальных и целевых пар.

Метки и поясняющие абзацы к результатам в Excel не добавлены. Коэффициенты калибровки загружены из Python; изменение исходного CSV требует повторной оценки. Строки и диапазоны книги не расширяются автоматически при добавлении дат.

## Python

Из корня репозитория:

```bash
python -m pip install -r requirements-models.txt
python evaluate_skill.py
python -m unittest discover -p "test_*.py"
```

Это воспроизводит статистические оценки, JSON и CSV. Скрипт не перезаписывает оформленные Excel-книги. `run.py` оставлен как прежний вариант с однократной проверкой на 30 днях; для актуальных показателей обеих групп используется `evaluate_skill.py`.
