# Прогноз уровня воды Амура у Хабаровска (Prophet)

Программа строит сезонный прогноз уровня воды на 365 суток моделью Prophet, проверяет его качество на последнем году данных и сохраняет графики и таблицы.

Prophet даёт долгосрочный сезонный фон - он не реагирует на конкретные осадки, поэтому для краткосрочного прогноза паводков нужна отдельная модель с погодными признаками.

## Структура проекта

```
prophet_flood/
├── forecast_short.py                          # программа
├── data/
│   └── amur_khabarovsk_clean_2002-2026.csv    # исходные данные
├── output/                                  # результаты (создаётся при запуске)
└── README.md
```

## Исходные данные

Файл `.csv` с суточными уровнями воды: колонка `date` (дата) и колонка `level_khabarovsk` (уровень воды, см). Данные охватывают период с 2002 года по август 2026 года, пропусков нет.

## Установка

Нужен Python 3.9-3.12. В терминале PyCharm (в начале строки должно быть `(.venv)`) выполните:

```
pip install prophet pandas numpy matplotlib
```

## Запуск

1. Откройте папку проекта в PyCharm.
2. Откройте `forecast_short.py` и нажмите Run.
3. Графики откроются в отдельных окнах. Закрывайте их по очереди, расчёт продолжится сам.

## Настройки

Все настройки находятся в начале `forecast_short.py`:

| Параметр | Что означает |
|---|---|
| `DATE_COL` | название колонки с датой |
| `VALUE_COL` | название колонки с уровнем воды |
| `HORIZON` | на сколько суток вперёд строится прогноз (365) |
| `TEST_DAYS` | сколько последних суток откладывается для проверки (365) |
| `LEAD_DAYS` | заблаговременность прогноза, суток (365): за такое время считается обычное колебание уровня σΔ |
| `CRITICAL` | критическая отметка уровня воды, см (470) |
| `OUTPUT_DIR` | папка для результатов |

Чтобы использовать другой файл, положите его в `data/` и поменяйте `FILE`, `DATE_COL` и `VALUE_COL`.

## Как работает программа

1. **Данные.** Файл читается и приводится к формату Prophet: колонка `ds` (дата) и колонка `y` (уровень воды).
2. **Проверка качества.** Модель обучается на всех данных, кроме последнего года, и прогнозирует этот год. Прогноз сравнивается с фактом.
3. **Прогноз.** Модель обучается на всех данных и строит прогноз на `HORIZON` суток вперёд с доверительным интервалом 80%.
4. **Сохранение.** Графики и таблицы записываются в папку `OUTPUT_DIR`.

## Результаты

В папке `output/`:

- `1_proverka.png`: сравнение факта и прогноза;
- `2_prognoz.png`: прогноз на 365 суток с интервалом и критической отметкой;
- `3_komponenty.png`: многолетний тренд и годовая сезонность;
- `prognoz.csv`: таблица прогноза по суткам (`ds` — дата, `yhat` — прогноз, `yhat_lower` и `yhat_upper` — границы интервала);
- `metrics.csv`: показатели качества.

## Показатели качества

| Показатель | Описание |
|---|---|
| MAE | средняя абсолютная ошибка, см |
| S (RMSE) | средний промах, см; крупные ошибки весят сильнее |
| NSE | насколько модель лучше прогноза «всегда средний уровень»: 1 - идеально, 0 - не лучше среднего |
| S/σΔ | ошибка относительно обычного колебания уровня за время прогноза; ≤0,5 - хорошо, ≤0,8 - удовлетворительно (критерий Росгидромета) |
| P% | доля прогнозов с ошибкой не больше допустимой (0,674·σΔ), % |
